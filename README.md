# 🧮 Quadratic Equation Solver

## 📌 Description

The Quadratic Equation Solver is a Python-based application that calculates the roots of equations in the form **ax² + bx + c = 0**. It determines whether the roots are real or complex and displays accurate results instantly using a simple graphical interface.

---

## ✨ Features

* Solves quadratic equations quickly
* Identifies nature of roots (real, equal, complex)
* Handles complex numbers
* Simple and user-friendly GUI
* Instant results

---

## 🛠️ Technologies Used

* Python
* Tkinter (GUI)
* Math / Cmath library

---

## 🧠 How It Works

1. User enters values of **a, b, and c**
2. The program calculates the discriminant:
   [
   D = b^2 - 4ac
   ]
3. Based on the value of D:

   * **D > 0** → Two real roots
   * **D = 0** → Equal roots
   * **D < 0** → Complex roots
4. Results are displayed on the screen
